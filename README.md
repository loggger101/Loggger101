### 🪐 Space economics

A four-repo stack answering whether an asteroid mining mission pays for itself:

| | |
|---|---|
| **[economicspace](https://github.com/loggger101/economicspace)** | The pipeline: build a catalog from public astronomy databases, price the minerals, cost the transportation, run the rocket equation and cost cascade to a ranked profitability table.<br/><img src="https://img.shields.io/badge/Python-1f3354?style=flat-square&logo=python&logoColor=white" alt="Python"> <img src="https://img.shields.io/badge/pandas-1f3354?style=flat-square&logo=pandas&logoColor=white" alt="pandas"> <img src="https://img.shields.io/badge/Docker-1f3354?style=flat-square&logo=docker&logoColor=white" alt="Docker"> |
| **[AsteroidCatalog](https://github.com/loggger101/AsteroidCatalog)** | Its Stage 1, split out: about 1.57 million asteroids from JPL SBDB, SsODNet, NEOWISE and MP3C, cross-matched, provenance-tagged per value, and given a cited composition estimate per taxonomy class. Published as frozen, pinnable releases.<br/><img src="https://img.shields.io/badge/Python-1f3354?style=flat-square&logo=python&logoColor=white" alt="Python"> <img src="https://img.shields.io/badge/Parquet-1f3354?style=flat-square&logo=apacheparquet&logoColor=white" alt="Parquet"> <img src="https://img.shields.io/github/v/release/loggger101/AsteroidCatalog?style=flat-square&label=release&labelColor=1f3354&color=5ba3dc" alt="Latest release"> <a href="https://www.loganmedwardsastrophy.com/asteroid-catalog.html"><img src="https://img.shields.io/badge/Project_page-5ba3dc?style=flat-square&logo=googlechrome&logoColor=white" alt="Project page"></a> |
| **[spacecost](https://github.com/loggger101/spacecost)** | Its Stage 3, split out as an installable package: cited reference tables for mission cost and mass estimation, every row carrying an inline citation.<br/><img src="https://img.shields.io/badge/Python-1f3354?style=flat-square&logo=python&logoColor=white" alt="Python"> <img src="https://img.shields.io/badge/pandas-1f3354?style=flat-square&logo=pandas&logoColor=white" alt="pandas"> <img src="https://img.shields.io/github/v/release/loggger101/spacecost?style=flat-square&label=release&labelColor=1f3354&color=5ba3dc" alt="Latest release"> <a href="https://www.loganmedwardsastrophy.com/spacecost.html"><img src="https://img.shields.io/badge/Project_page-5ba3dc?style=flat-square&logo=googlechrome&logoColor=white" alt="Project page"></a> |
