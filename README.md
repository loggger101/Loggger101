### 🪐 Space economics

A four-repo stack answering whether an asteroid mining mission pays for itself:

| | |
|---|---|

| **[AsteroidCatalog](https://github.com/loggger101/AsteroidCatalog)** | Its Stage 1, split out: about 1.57 million asteroids from JPL SBDB, SsODNet, NEOWISE and MP3C, cross-matched, provenance-tagged per value, and given a cited composition estimate per taxonomy class.
